## Описание проекта

**Code Complexity Analyzer** — это расширение для VS Code, которое помогает разработчику быстро оценить читаемость и структурную сложность кода. Плагин анализирует выделенный фрагмент кода прямо в редакторе и выводит сводку метрик.

В основе работы плагина лежат классические алгоритмы и структуры данных:
1. **Стек (Stack)** — для отслеживания парности и глубины вложенности фигурных скобок `{ }`.
2. **Множество (Set)** — для быстрого поиска ключевых слов ветвления и расчета цикломатической сложности.

---

## Возможности плагина

* **Расчет максимальной вложенности (Nesting Depth):** показывает, насколько глубоко вложены друг в друга циклы и условия («лесенка» в коде).
* **Расчет цикломатической сложности (Cyclomatic Complexity):** определяет количество независимых путей выполнения программы на основе операторов `if`, `for`, `while`, `case`, `catch`, `&&`, `||`, `?`.
* **Итоговая оценка качества:** автоматическая классификация фрагмента по шкале:
  * `Низкая` — код простой, легко читается и тестируется.
  * `Средняя` — умеренная сложность, нормальный рабочий код.
  * `Высокая` — код перегружен ветвлениями, рекомендуется провести рефакторинг.
* **Удобный запуск:** анализ вызывается по нажатию одной комбинации клавиш.
* **Вывод:** результат диалоговом окне.

## ⌨️ Горячие клавиши и использование

1. Откройте любой файл с кодом (поддерживаются C++, JavaScript, TypeScript, Java, C# и др.).
2. Выделите интересующую функцию или фрагмент кода (если ничего не выделено, плагин проверит весь файл).
3. Нажмите комбинацию клавиш:
   * `Cmd + Option (Alt) + C`
   *(Также команду можно вызвать через палитру: `Cmd+Shift+P` ➔ ввести `Analyze Code Complexity`).*
